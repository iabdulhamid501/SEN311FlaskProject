# Loft City - Apartment Booking System

## Project Overview
A comprehensive web-based apartment booking system built with Flask and MySQL.

## Technologies Used
- Python 3.8+
- Flask 2.3.2
- MySQL 8.0
- Bootstrap 4.6
- HTML5, CSS3, JavaScript

## Installation Instructions

### 1. Install XAMPP
- Download from https://www.apachefriends.org/
- Start Apache and MySQL services

### 2. Create Database
- Open phpMyAdmin at http://localhost/phpmyadmin
- Create database: `loft_city_db`
- Import the SQL file from `database/loft_city_db.sql`

### 3. Install Python Dependencies
```bash
pip install -r requirements.txt
